# Driver App

Independent Flutter application for delivery drivers.

## Assigned features

- Google Sign-In, identity verification, document upload
- Online/offline availability and delivery offers
- Accept/reject delivery, restaurant/customer navigation
- Live map, location sharing, route recalculation, ETA
- Proof of delivery: photo, signature, cash-on-delivery confirmation
- Wallet, earnings, delivery history, ratings, support, settings

The app consumes the shared API contract under `../backend/docs/api-contract.md`.
