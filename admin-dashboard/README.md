# Admin Dashboard

Independent Flutter web dashboard for platform operations.

## Assigned features

- Manage restaurants, subscriptions, plans, customers, and drivers
- Manage cities, delivery zones, commissions, payments, and coupons
- Advertising, complaints, support, analytics, AI monitoring, and audit logs
- Role-specific workspaces for Platform Owner, Platform Admin, Support, and Finance

The dashboard consumes the shared API contract under `../backend/docs/api-contract.md`.
