# Customer App

Independent Flutter application for customers and guests.

## Assigned features

- Google Sign-In and guest browsing
- Restaurant discovery, search, categories, filters, nearby restaurants
- Offers, best sellers, restaurant details, menus, add-ons, favorites
- Cart, coupons, saved addresses, maps, delivery-zone and fee preview
- Checkout, live order tracking, driver location, ETA
- Notifications, restaurant/driver chat, ratings, reorder, order history
- Profile, language, and theme

The app consumes the shared API contract under `../backend/docs/api-contract.md`.
